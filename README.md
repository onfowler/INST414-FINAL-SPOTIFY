## Project Overview
This repository contains a multi-layered data science analysis designed to solve the "Cold Start Problem" for Spotify Recommendation Algorithm Developers. When thousands of new songs are uploaded daily, backend systems struggle to accurately categorize and recommend them without human intervention. 

This project proposes a hybrid recommendation pipeline that combines raw audio mathematical features with social network influence to automatically categorize new uploads.

## Methodology
This project integrates three distinct machine learning and data science techniques:
1. **Unsupervised Learning (Clustering):** We applied K-Means clustering (k=6) using Euclidean distance to natively group songs by their audio metrics (e.g., energy, acousticness, valence) to understand the natural mathematical shapes of the database.
2. **Network Science (Collaboration Dynamics):** We built an undirected network graph mapping "featured artist" collaborations across a decade of hit music. Using `networkx`, we calculated Degree and Betweenness Centrality to identify "bridge" artists (like David Guetta) who cross-pollinate genres. 
3. **Supervised Learning (Classification):** We trained a Random Forest Classifier on the continuous numerical audio features to predict a track's primary genre, achieving an automated baseline accuracy of 64.5%. 

The final actionable insight proposes using the Random Forest classification as a baseline tag, and utilizing the Network Centrality metrics as an algorithmic override to correct misclassifications based on an artist's collaborative social circle.

## The Data
The data utilized is the "Top Hits Spotify from 2000-2019" dataset (`songs.csv`), which contains roughly 2,000 top tracks alongside 18 specific metadata fields and audio features generated by the official Spotify Web API.

* `network_analysis.py`: The network science script utilizing Regular Expressions (`re`) to extract featured artists and `networkx` to calculate centrality metrics (Module 2).
